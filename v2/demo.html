    What is real and what is simplified. The classifier (the exported weights of the trained TF-IDF and logistic regression model), the explanation words, the prompt-injection patterns, the autonomy policy and the ticket grouping all run in this page. The browser version matches the Python original on all 60 test tickets I checked. Simplified here: there is no database or API, grouping uses the model's own word vectors, and retraining is not performed in the browser. The model was trained on synthetic tickets, so accuracy on real tickets would be lower. The full system (FastAPI, SQLite audit trail, retraining and 46 tests) is in the GitHub repository.
